Precision Coach CRM

A private, single-owner CRM for Precision Coach's online/in-person health and fitness coaching business. It captures leads from Instagram-driven lead magnets and call bookings, moves them through a sales pipeline from first touch to closed deal, and manages the ongoing client relationship — all in one owned, on-brand system instead of a stack of rented "coach funnel" tools.

Next.js TypeScript Tailwind CSS Prisma PostgreSQL Resend Cloudflare R2 Google Calendar API

What the app does

  • Contacts

    Full contact records with a searchable, filterable list and a chronological activity timeline.

  • Deals & Kanban Pipeline

    Editable pipeline stages, drag-and-drop deal cards, and per-column plus total pipeline value.

  • Follow-Ups & Tasks

    Tasks on any contact or deal, plus one global "My Tasks" view with overdue items flagged.

  • Lead Magnet Landing Page

    On-brand, mobile-first link-in-bio page that gates PDF downloads behind a name + email form.

  • Call Booking / Calendar

    Self-service booking against real availability, with conflict-checking and a one-way Google Calendar push.

  • Lead Segmentation & One-Off Email

    Filter contacts by source/tag to spot cold leads, and send a single one-off email from a contact record.

  • Dashboard Summary

    At-a-glance pipeline value, tasks due today/overdue, and new leads this week.

Out of scope (v1)

  • Multi-user / team accounts — explicit stretch goal, not needed for a single-admin v1.
  • Mobile app or browser extension — unnecessary overhead for a single-admin web tool.
  • OAuth / social login — one admin user; email + password is simpler and sufficient.
  • Custom Stripe checkout — existing Payment Links are linked out to directly; building custom checkout duplicates work.
  • Built-in bulk email marketing / automation sequences — a dedicated email marketing tool does this better; connect one externally if needed.
  • SMS reminders (Twilio) — adds a new provider and cost before the core loop is proven; the due-today/overdue dashboard widget is the v1 reminder mechanism.
  • Two-way live Google Calendar sync — real-time bidirectional sync is a much heavier lift than v1 needs; a one-way push covers it.
  • Public API / advanced analytics — no current use case beyond the dashboard summary.

External integrations

Resend

Transactional email

Sends booking confirmations, call reminders, and one-off contact emails.

Credentials needed

  • Resend API key
  • Verified sending domain (precisioncoach.net DNS records)

Cloudflare R2

File storage

Stores lead magnet PDFs and cover images. S3-compatible, no egress fees, and portable across hosts.

Credentials needed

  • Cloudflare account
  • R2 API access key + secret
  • R2 bucket name

Google Calendar API

Calendar push

Creates a matching event on your Google Calendar whenever a call is booked (one direction only, no live sync back).

Credentials needed

  • Google Cloud project
  • OAuth client ID + secret
  • One-time consent grant for your Google account

Stripe Payment Links

Payments

The landing page links out to your existing Payment Links for checkout. No custom Stripe integration is built.

Credentials needed

  • None — just your existing Payment Link URLs

Milestones

1

Scaffold, Auth & Dashboard Shell

Stands up the Next.js app, email/password login for the single admin, and the on-brand (black background, gold/amber accent, off-white text) dashboard shell every later milestone builds inside.

What gets built

  • Next.js + TypeScript + Tailwind project scaffold, deployable to Vercel/Railway/Render
  • Prisma + PostgreSQL connection and the User model
  • Email/password login for the seeded admin account (no public signup)
  • On-brand dashboard shell with nav placeholders for Contacts, Deals, Tasks, Bookings, Leads

Not in this milestone

  • Any real Contacts/Deals/Tasks/Booking functionality (placeholders only)
  • Public lead magnet page
  • Any third-party integration wiring (Resend, R2, Google Calendar)

Done when: You can log in with your admin email/password and land on the fully-themed dashboard shell with working nav to empty section placeholders.

2

Contacts Module

Builds the CRM core — full contact records and a searchable, filterable list.

What gets built

  • Create / edit / delete a Contact with all fields
  • Contact list, searchable and filterable by tag, source, and deal status
  • Contact detail page showing the full record

Not in this milestone

  • Activity timeline rendering (Milestone 7)
  • Deals, tasks, or bookings UI

Done when: You can create a contact, see it in a searchable/filterable list, and open its full detail record.

3

Deals + Kanban Pipeline

Adds the sales pipeline — deals linked to contacts, visualized as a drag-and-drop Kanban board.

What gets built

  • Create a Deal linked to a Contact (value, stage, expected close date, notes)
  • Editable pipeline stages (default: New Lead → Contacted → Call Booked → Call Completed → Proposal Sent → Won → Lost)
  • Kanban board: one column per stage; cards show contact name, value, days in stage
  • Drag-and-drop between columns, persisting the new stage
  • Per-column and total pipeline value totals

Not in this milestone

  • Automatic deal creation from bookings or lead magnet submissions (Milestones 5 & 6)
  • Task/follow-up UI

Done when: You can create a deal, see it as a card in the right column, drag it to a new stage with the change persisting, and see correct column/total values.

4

Tasks + Global Dashboard

Adds follow-up tasks on contacts and deals, plus one global view of everything due.

What gets built

  • Add a follow-up task (description + due date/time) to any Contact or Deal
  • Global "My Tasks" view: every open task, sortable by due date, overdue items flagged
  • Mark a task complete; completing one optionally prompts creating the next follow-up

Not in this milestone

  • Email/SMS reminder delivery — the due-today/overdue view is the v1 reminder mechanism
  • Dashboard summary widget (Milestone 7)

Done when: You can add a task to a contact or deal, see it in the global My Tasks view sorted by due date with overdue ones flagged, and mark it complete.

5

Lead Magnet Landing Page

Builds the public, on-brand link-in-bio page that turns Instagram traffic into tagged Contacts.

What gets built

  • Public page listing active lead magnets (title, description, cover image) — on-brand, mobile-first
  • Name + email form gates each PDF download
  • Submitting creates/updates a Contact, tags them with the lead magnet, sets source
  • Featured paid-offer section linking to your existing Stripe Payment Links
  • Link to the call booking page
  • Admin screen to add/edit/deactivate lead magnets

Not in this milestone

  • The booking page itself (Milestone 6)

Done when: A visitor can open the public page on mobile, submit their email, download the gated PDF, and you see a new tagged Contact appear in the CRM.

6

Booking / Calendar Module

Lets visitors self-book a consultation call against your real availability, with calendar and email follow-through.

What gets built

  • Admin screen to set recurring weekly availability and block off specific dates
  • Public booking page showing open slots; visitor picks a time and submits their info
  • Booking creates/updates the Contact, creates a Deal at "Call Booked" if none exists, and creates a conflict-checked Booking
  • Creates a matching event on your Google Calendar (one-way push)
  • Confirmation email to the visitor, plus a reminder email closer to the call time

Not in this milestone

  • Two-way sync — changes made in Google Calendar don't flow back
  • Rescheduling flows beyond marking a booking cancelled

Done when: A visitor can book an open slot; you see the Contact/Deal/Booking created, a matching Google Calendar event, and they receive a confirmation email.

7

Polish: Timeline, Segmentation & Dashboard Summary

Ties everything together with a chronological view per contact, lead follow-up tools, and an at-a-glance dashboard.

What gets built

  • Activity timeline on each Contact showing every touchpoint chronologically
  • Main dashboard: total pipeline value, tasks due today/overdue, new leads this week
  • Contact segmentation view: filter by source/tag (e.g., downloaded eGuide but never booked)
  • One-off email: send a single email to a contact from their record

Not in this milestone

  • Bulk email sequences or marketing automation
  • SMS reminders

Done when: Every contact shows its activity history, the dashboard shows live pipeline/task/lead stats, and you can send a one-off email to any contact.
